# Tutorials

No tutorial exists yet. The first tutorial arrives with version 0.2, when a
guest file can provision a real guest.

A tutorial will follow one rule. The reader starts from nothing and finishes
with a working guest. Every step runs on the reader's machine.

## Planned tutorial

1. Install the toolchain.
2. Write one guest file.
3. Run the check.
4. Provision the guest.
5. Open the service in a browser.

## Until then

- A reader who wants the model reads [Layers](../explanation/layers.md).
- A reader who wants a procedure reads
  [Provision a guest](../how-to/provision-a-guest.md).
- A reader who wants a fact reads the [Glossary](../glossary.md).
